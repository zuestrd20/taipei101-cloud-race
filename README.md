# 101 雲端競速

繁體中文 HTML5 / Three.js 3D 攀登競速同人遊戲。玩家選擇一隻寶可夢，與三位電腦選手沿著台北101外側的三線螺旋天空步道登頂。第一個抵達101F者獲勝，本次更新為3倍基礎跑速，技能與護盾的秒數不變。

## 開啟遊戲

### 已編譯版本（建議）

將 `dist/` 內容放進任意靜態 HTTP/HTTPS 主機；也可在 `dist/` 目錄執行：

```sh
python3 -m http.server 8080
```

然後在瀏覽器開啟 `http://localhost:8080`。請勿直接雙擊 `index.html` 使用 file://，瀏覽器會阻擋 ES module 或 GLB 載入。所有3D模型與程式都隨包提供，不依賴外部CDN或字型服務。

### 原始碼

需要 Node.js 20.19+ 或22.12+（本次以24.19驗證）。

```sh
npm ci
npm run dev -- --host 127.0.0.1
npm test
npm run build
```

Vite 將輸出至 `dist/`，相對路徑可放在子目錄。無後端、登入、第三方追蹤或雲端資料庫。個人紀錄與設定只存於本機 localStorage。

## 操作

| 操作 | 鍵盤 | 手機 |
|---|---|---|
| 向上跑 | W / ↑ | 按住 ▲ |
| 減速、退後 | S / ↓ | 可停止前進 |
| 換線（本版方向對調） | A / ← 向畫面左；D / → 向畫面右 | ◀ ▶，與鍵盤一致 |
| 跳躍 | 空白鍵 | 跳躍按鈕 |
| 擊退波 | J | 擊退波按鈕 |
| 前射道具 | F | 前射道具按鈕 |
| 防護罩 | K | 防護罩按鈕 |
| 衝刺 | L / Shift | 衝刺按鈕 |
| 旋轉視角 | 滑鼠左鍵拖曳3D畫面 | 單指拖曳3D畫面 |
| 回到跟隨視角 | C | 右上「跟隨視角／重置視角」 |
| 暫停 | Esc / P | 右上暫停 |

設定可調整音量、畫質、自動前進；手機建議啟用自動前進。頁面失焦或切換分頁會暫停。

## 賽事規則

- 3秒倒數後開跑。玩家與AI使用同一套移動、體力、攻擊、護盾和碰撞規則。
- 10隻角色均為不同外觀，基礎能力一致，沒有付費或隱藏能力差異。
- 紫色彈藥箱位於中線8、28、48、68、88F，最多攜帶1發。衝擊彈沿賽道向前飛行，射程6層、發射冷卻0.8秒，只命中前方相近跑道對手，不能倒打身後。普通盾抵擋，完美盾會摧毀彈體並反擊射手。
- 近距離同跑道可攻擊；腳下紅圈表示0.24秒出招預警。防護罩最初0.22秒可完美格擋並反彈，較晚則一般格擋。
- 攻擊有擊退與平衡值傷害；連續命中可能讓對手掉落。跳躍能閃避地面攻擊。
- 三線步道有障礙、風場與缺口。跳躍可越過；護盾可擋障礙和風場，但不能補上缺口。
- 每10層會保存檢查點、恢復體力。失足會以安全繩拉回檢查點，沒有永久死亡。
- 中間跑道5、15、25…95F有金色體力補給，每隻選手可各拿一次。
- 內圈12、32、52、72、92F有綠色跳板，跳躍通過可前進1.4層。
- 落後領先者4層以上會漸增追趕加成，最多8%；玩家與AI皆適用。
- 冠軍出現即結束比賽。只有玩家真正完成101F才記錄個人登頂時間。

## 驗證狀態與限制

- 正式版Vite build通過。
- 11個GLB使用Three.js完整解析，具有有效mesh與3D尺寸；複製檔案與原提供檔案一致。
- 純JS賽局測試涵蓋倒數、種子重現、移動、體力、冷卻、完美格擋、擊退掉落、缺口、檢查點、補給、捷徑、追趕、AI完賽、玩家可勝與前射道具。
- 更新後重新驗證3倍跑速、前射道具命中/身後不命中、護盾與完美反擊、高速移動碰撞與AI完賽。30個種子以0.25秒較粗幀間隔測試，AI均於約63.48–81.20秒完賽；熟練玩家測試73.25秒獲勝。
- 視角測試涵蓋原跟隨位置相容、旋轉角度範圍、塔身與地面邊界、相對玩家跟隨、指標捕捉與多指競爭、UI隔離、C／按鈕重置、暫停／重開清除手勢。
- DOM事件測試涵蓋10角色選擇、教學、設定保存、鍵盤/觸控技能與對調方向、道具庫存HUD、開始/暫停/關閉/重開/返回選單、結果與本機紀錄。
- **尚未完成GPU畫面、真實鍵鼠遊玩、觸控裝置與音訊實機驗證。** 製作環境的瀏覽器不提供WebGL2；前版公開頁面已驗證可載入並正確顯示不支援提示。未以危險GPU參數繞過限制，亦未將示意圖當作遊戲截圖。
- 此版本需要WebGL2。若不可用，頁面會顯示明確提示與重新檢查按鈕。請使用支援WebGL2的Chrome、Edge、Firefox或Safari；低階手機可選省電畫質。
- 渲染、鏡頭構圖與手機手感尚待有GPU的瀏覽器覆核；不可將純模擬/DOM測試視為完整視覺驗收。

## 檔案結構

- `src/main.js`：GLB載入、Three.js場景/賽道/角色、UI、輸入、音效
- `src/camera-controls.js`：自由視角數學、碰撞界限與指標拖曳
- `src/simulation.js`：與渲染分離的固定60Hz賽局和AI
- `src/style.css`：桌面與手機介面
- `test/`：賽局、素材、DOM事件測試
- `public/models/`：11個原始GLB
- `dist/`：可直接託管的輸出
